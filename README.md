인천산업정보학교 제빵 수업 연계 노동인권교육(2026. 11. 12.)에서 쓰는 모둠 활동도구와 교사용 수업 진행판입니다.

- 모둠 태블릿: 로그인 화면에서 **1·2·3모둠** 버튼을 누르고 비밀번호를 넣으면 우리 모둠 화면이 열립니다.
- 교사용 TV: **교사** 버튼으로 로그인하면 수업 진행판(타이머, 모둠 결과 모아보기, 해설 공개, 출구 퀴즈, 권리 카드)이 열립니다.
- 교사용 TV: **발표 화면(PPT)** 버튼으로 로그인하면 바로 발표 화면이 열립니다(보기 전용, 타이머·모둠 결과·퀴즈·말풍선 실시간).
- 비밀번호 바꾸기: 교사 화면 맨 아래 **계정 비밀번호 설정**에서 모든 수업 계정의 비밀번호를 바꿀 수 있습니다.
- 참관 태블릿: **참관 (보기 전용)** 버튼으로 로그인하면 수업 단계·모둠 진행 상황·퀴즈·학생 생각을 보기 전용으로 봅니다.
- 생각 말풍선: 모둠·교사·참관 화면 아래와 발표 화면 17에 학생들의 '노동인권에 대한 내 생각 한마디'가 하린 주위 말풍선으로 바로 떠오릅니다.
- 모둠 기록은 Supabase에 저장되어 실시간으로 공유됩니다. 각 모둠은 자기 모둠 기록만 고칠 수 있고, 참관 계정은 읽기만 합니다.
