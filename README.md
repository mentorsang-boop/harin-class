# 하린의 첫 직장 한 달 · 수업도구

인천산업정보학교 제빵 수업 연계 노동인권교육(2026. 11. 12.)에서 쓰는 모둠 활동도구와 교사용 수업 진행판입니다.

- 모둠 태블릿: 로그인 화면에서 **1·2·3모둠** 버튼을 누르고 비밀번호를 넣으면 우리 모둠 화면이 열립니다.
- 교사용 TV: **교사** 버튼으로 로그인하면 수업 진행판(타이머, 모둠 결과 모아보기, 해설 공개, 출구 퀴즈, 권리 카드)이 열립니다.
- 모둠 기록은 Supabase에 저장되어 실시간으로 공유됩니다. 각 모둠은 자기 모둠 기록만 고칠 수 있습니다.

## 파일

| 파일 | 내용 |
| --- | --- |
| `index.html` | 로그인·모둠 화면·수업 진행판 |
| `config.js` | Supabase 주소와 공개용(publishable) 키 |
| `supabase-setup.sql` | 표와 권한(RLS) 설정 |
| `assets/` | 학교 로고 |

비밀번호는 이 저장소에 넣지 않습니다.
